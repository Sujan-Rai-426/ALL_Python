

## WE USED "WHILE Loop" instead of "For Loop" when there is no fixed range of loop. AND need to run loop till the condition is satisfied. 

``` base

    # Basic concept
    counter = 1
    while counter <= 5:
        print(f"Count: {counter}")
        counter += 1

    # Output:
    # Count: 1
    # Count: 2
    # Count: 3
    # Count: 4
    # Count: 5

```
